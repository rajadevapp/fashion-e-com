# Luxury Minimal — Fashion E-Commerce Website

A modern, elegant, and responsive fashion e-commerce website designed with a luxury minimal aesthetic. The project focuses on clean layouts, sophisticated typography, smooth animations, and interactive shopping features.

## ✨ Features

- **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- **Modern Homepage** — Hero slider, brand showcase, new arrivals, popular products, and limited-edition collections.
- **Product Listing** — Dynamic product cards with category and price filters.
- **Product Sorting** — Organize products based on available sorting options.
- **Wishlist** — Add or remove favorite products with a dynamic wishlist counter.
- **Shopping Cart** — Add products, remove items, and increase or decrease quantities.
- **Live Cart Summary** — Automatically updates item counts and subtotal.
- **Pagination** — Navigate through product listings with smooth scrolling.
- **Custom Dropdowns** — Interactive dropdown menus and filter controls.
- **Scroll Animations** — Smooth reveal effects and transitions.
- **Contact Page** — Contact form and customer information section.
- **Reusable SVG Icons** — Custom icons for navigation, wishlist, cart, and social links.

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic markup.
- **CSS3** — Responsive layouts, gradients, animations, and styling.
- **JavaScript (Vanilla)** — Product rendering, filtering, sorting, pagination, wishlist, and cart functionality.
- **SVG** — Scalable icons and interface elements.

## 🎨 Design Concept

The website follows a luxury minimal design direction, featuring:

- Neutral ivory and beige backgrounds.
- Elegant black and charcoal accents.
- Sophisticated typography.
- Spacious layouts and high-quality fashion imagery.
- Subtle hover effects and smooth transitions.

## 🛍️ Shopping Features

### Wishlist
- Add products to the wishlist.
- Remove products from the wishlist.
- View selected products in a sidebar.
- Display the current wishlist count.

### Shopping Cart
- Add products to the cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- Automatically calculate the subtotal.
- Display the total quantity in the navigation badge.

### Product Filtering
- Filter products using available categories.
- Filter by price range.
- Sort products using supported sorting options.
- Navigate between product pages using pagination.

## ⚠️ Current Limitations

- Product data is managed on the frontend.
- Wishlist and cart data stored in JavaScript arrays reset when the page reloads.
- No backend, user authentication, payment gateway, or order management is included unless implemented separately.
- The contact form requires a backend or third-party service to send messages.
